Evolving to Match Capabilities

Improving Harness Self-Evolution via Skill Adaptation

Well-crafted agent skills improve GPT-5.6-luna by +31.1 points — and degrade Gemma-4-E4B by −8.8. In 86% of failed weak-model runs, the violated requirement is already written in the skill. We diagnose these failures, distill the diagnosis into a meta-skill — a fixed rewriting protocol — and show it lifts weak executors by +5.1 to +14.1 points in one-shot adaptation and +2.0 to +5.1 points after five rounds of self-evolution.

Takeaways

1 Skills are not model-agnostic: the same guidance that lifts frontier models can sink weak ones.
2 Most weak-model failures violate requirements the skill already states — the problem is packaging, not content.
3 A fixed meta-skill, distilled from failure attribution, adapts skills to the executor — with no execution evidence needed.
4 Inside self-evolution, the meta-skill turns trajectories and verifier feedback into better skills, round after round.
